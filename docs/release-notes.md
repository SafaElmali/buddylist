buddylist brings Claude Code, Codex, Gemini, OpenCode and Hermes into a classic messenger buddy list.

This release contains the latest changes that passed the automated tests and Mac, Windows and Linux builds.

## Install on an Apple Silicon Mac

1. Download **buddylist-mac-arm64.dmg** below.
2. Open the disk image and drag **buddylist** to **Applications**.
3. Open buddylist from Applications.

**Updating an existing installation?** Copies with automatic updates download each new version by themselves and ask you to restart buddylist to install it. A copy of v0.2.7 or earlier is replaced by hand this once: quit buddylist, then drag this version into **Applications** over it.

**Coming from Agent Messenger?** That is what buddylist was called before. Quit Agent Messenger, drag **buddylist** to **Applications**, and delete Agent Messenger from there. Your contacts and history come along the first time buddylist opens.

This release is signed with a Developer ID and notarized by Apple, so it opens like any other app you download.

## Install on Windows (x64)

Download **buddylist-win-x64.exe** below and run it. Install Git for Windows for Claude Code and project scripts. This installer is unsigned. New versions download in the background and install when you restart buddylist.

## Install on Linux (x64)

Download **buddylist-linux-x86_64.AppImage**, make it executable (`chmod +x buddylist-linux-x86_64.AppImage`), and open it. AppImage installations update in place. Your system needs FUSE support to mount the image.

On Debian or Ubuntu, you can instead download **buddylist-linux-amd64.deb** and run `sudo apt install ./buddylist-linux-amd64.deb`. Install the new package when an update is announced.

Intel Mac and ARM Windows/Linux installers are not provided. Use your own agent accounts: Claude Code is bundled; Codex, Gemini, OpenCode and Hermes need their respective CLI installed and signed in.
