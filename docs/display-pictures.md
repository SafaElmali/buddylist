# Your own display pictures

Your display picture, and your contacts', can be a picture of your own. Drop the files into `pack/pictures/` inside [the app's data folder](getting-started.md#where-your-data-lives):

| System  | Picture folder                                                                                |
| ------- | --------------------------------------------------------------------------------------------- |
| macOS   | `~/Library/Application Support/buddylist/pack/pictures/`                                      |
| Windows | `%APPDATA%\buddylist\pack\pictures\`                                                          |
| Linux   | `~/.config/buddylist/pack/pictures/`, or `$XDG_CONFIG_HOME/buddylist/pack/pictures/` when set |

- GIF, PNG (and animated PNG), WebP and JPEG files work.
- Restart the app to see new files.

Clicking your picture then offers them next to **Browse...**. The ▾ next to a contact's picture, or a click on the picture in **Edit contact...**, lists them too.
