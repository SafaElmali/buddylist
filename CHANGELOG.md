# Changelog

Version-by-version changes to the public buddylist downloads, newest first. Dates are the original publication dates.

[Download the latest version](https://github.com/SafaElmali/buddylist-releases/releases/latest) · [Installation instructions](README.md#install) · [Website](https://buddylist.dev/)

## [v0.2.5](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.5) — 2026-10-11

- A welcome wizard signs you in to Claude without a terminal and ends in your first contact.
- A dark theme, and a **Professional** look beside the messenger one, under **Tools > Theme** and **Tools > Look**.
- A **Settings** window for the app and each project: scripts, variables, branches, instructions and files to copy.
- Review a pull request beside the conversation: commits, review comments under their lines, replies and resolving. A **Create PR** button sits in the toolbar.
- **Browser** and **Helpers** tabs beside the conversation, and a context meter showing what fills the context window and your plan’s limits.
- Your contacts listed beside a conversation, and models invited into a conversation without joining the contact list.
- A Claude contact can check back on its own, for example to tell you when CI is green.
- buddylist says when a newer version is out and downloads it for you.
- **Help > Send feedback** for feedback, bug reports and feature requests.
- Faster history search, smoother streaming of long replies, and fixes for crashes, lost replies and settings that could be wiped.
- Agent Messenger is now buddylist, at [buddylist.dev](https://buddylist.dev/). Your contacts and conversations move over the first time you open it.

## [v0.2.4](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.4) — 2026-10-07

- Links in messages you send are now clickable.
- Agent questions are presented as slides, making multiple questions easier to work through.
- A Changes button in the conversation toolbar opens your project’s uncommitted changes.
- Square window corners on macOS better match the classic messenger appearance.
- Release downloads are published directly from the build, avoiding failures caused by temporary build-storage limits.

## [v0.2.3](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.3) — 2026-10-07

- Maintenance release for the website’s automatic deployment process.
- No application feature changes compared with v0.2.2.

## [v0.2.2](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.2) — 2026-10-07

- Ask a Claude contact to open terminals beside your conversation, including running a command in a new terminal.
- Hands-free voice clips can send automatically when you stop speaking.
- Smaller downloads through improved installer compression and more compact bundled winks.
- Custom wink files can replace bundled ones in another supported format.
- Fixed incorrect terminal character spacing after display-scale changes.
- Improved model, effort and mode badges in narrow conversations.
- The website includes a guided interactive demo with a simulated terminal and an example code change.

## [v0.2.1](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.1) — 2026-10-07

- Inspect uncommitted files and diffs in the Changes tab beside a conversation.
- See merged pull requests, merge conflicts and check status in the contact list.
- Let contacts choose effort levels automatically for messages and group conversations.
- Contacts are grouped by project by default, with clearer worktree progress and faster contact removal.

## [v0.2.0](https://github.com/SafaElmali/buddylist-releases/releases/tag/v0.2.0) — 2026-10-07

- First public packaged release for Apple Silicon Macs.
- Chat with Claude Code, Codex, Gemini and OpenCode through a classic messenger buddy list using your own agent accounts.
